# [RHE.ILL.396] Неадекватность существующей нотации для явного выражения многоуровневых классификаций

## Source

Объект класса (такой как red), являющийся членом другого класса (colours),
должен быть изображён дважды в диаграмме: один раз как lozenge поверх овала класса red
(содержащего членов), и ещё раз просто как lozenge внутри овала класса colours.

## Structural Core

Необходимость дублирования графического символа отражает напряжение между двумя ролями объекта (быть контейнером для членов И быть членом другого класса одновременно)

## Boundaries (breaks_when)

когда переходят к более явной нотации (как в Part E), где дублирование становится излишним; эта проблема специфична только для chosen notational form
