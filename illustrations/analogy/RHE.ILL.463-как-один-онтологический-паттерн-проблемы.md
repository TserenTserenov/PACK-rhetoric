# [RHE.ILL.463] Как один онтологический паттерн проблемы распространяется иерархически от базовых сущностей к производным структурам

## Source

In logical semantics, a car object is a three-dimensional extension now and was another different three-dimensional extension yesterday and these are somehow the same car. What then is the class cars? In logical semantics, classes share the same mysterious sameness over time as physical bodies.

## Structural Core

Если физический объект имеет проблему идентичности во времени в одной семантике, то класс (построенный из таких объектов) имеет туже проблему; решение для объектов решает и для классов.
