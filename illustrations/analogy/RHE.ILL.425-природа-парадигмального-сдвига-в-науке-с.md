# [RHE.ILL.425] Природа парадигмального сдвига в науке: смена интерпретирующей схемы без изменения фактического материала

## Source

In Chapter 1, we used an ambiguous picture as an analogy for how paradigm shifts work.
When we shift from seeing two faces to seeing a vase, nothing in the underlying picture
changes. In the same way, the shift to object semantics does not involve any new facts,
just a new way of seeing the old facts.
