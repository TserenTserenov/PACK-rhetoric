# [RHE.ILL.225] Paradigm resistance is domain-agnostic—even technical paradigm shifts face identical psychological obstacles as scientific ones

## Source

When an object-oriented programming language is introduced into a traditional programming 
environment, programmers trained in traditional programming often still use traditional 
patterns to program in the new language. They have been taught to see and ignore other 
patterns needed to make effective use of the new language, resulting in learning difficulty.
