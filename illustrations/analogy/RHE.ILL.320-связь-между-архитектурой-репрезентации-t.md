## Source

Multiple classification allows a lattice structure across the primary-secondary divide, 
with entities able to belong to multiple parent categories. Single classification 
preserves a tree structure, where each entity has exactly one parent category. 
The structural difference mirrors the logical constraint of the paradigm.
