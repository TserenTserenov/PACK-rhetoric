# [RHE.ILL.152] экзокортекс как функциональное продолжение мозга, а не внешнее хранилище

## Source

Записи - экзокортекс, продолжение мозга, поэтому есть смысл их использовать примерно также, как использует мысли мозг. В мозге все работает через предсказания. Мозг сравнивает новую входящую информацию с предсказанием, если есть какие-то расхождения с предсказанием, то предсказание корректируется и создается новое предсказание.

Если обе системы (биологическая и артефактная) работают по одному принципу (ошибка предсказания → коррекция), то управление одной переносится на другую
