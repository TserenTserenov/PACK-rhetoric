# [RHE.ILL.001] Болид = Пилот + Машина

## Иллюстрация

Болид Формулы-1 — это не просто машина. Без пилота он стоит. Без машины пилот бежит пешком.
Результат гонки — продукт системы «пилот + болид»: пилот задаёт стратегию и реакцию,
машина реализует скорость и управляемость. Созидатель — то же самое: человек + IWE.

## Структурное ядро

Пилот соответствует человеку, болид — IWE, потому что оба описывают структуру «деятель + усиливающий
инструмент», где результат принадлежит системе в целом, а не одному из компонентов.
Отношение: роль (пилот/человек) + инструмент (болид/IWE) = Созидатель.

## Ломается когда

- Если акцент смещается на «IWE делает всё сам» → болид без пилота никуда не едет. Аналогия
  защищает от этого смещения, если правильно расставить акцент.
- Если аудитория не знакома с Формулой-1 → можно заменить на любую «роль + инструмент» пару.

## Как использовать

Вводить при первом объяснении концепта Созидателя. Фраза-мостик: «Представьте себе болид
Формулы-1...» → потом «Созидатель — то же самое, только вместо болида — IWE».
