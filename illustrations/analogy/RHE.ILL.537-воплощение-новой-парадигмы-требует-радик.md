# [RHE.ILL.004] воплощение новой парадигмы требует радикальной переструктуризации коммуникативных инструментов, а не только идей

## Source

In language, time is currently described using tense. If language is to reflect the 
object paradigm's amalgamation of time and space, we need to develop a tenseless 
language that describes space-time. This would be a substantial change.
