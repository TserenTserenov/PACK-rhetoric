# [RHE.ILL.418] Identity persists through time when parts are changed gradually if the whole maintains a common purpose, despite the logical paradigm's inability to explain it through extension alone.

## Source

A ship of which a considerable part has been chang'd by frequent reparations, is
still considered as the same; nor does the difference of materials hinder us from
ascribing an identity to it.

## Structural Core

[Gradual material replacement] + [persistent common purpose] → [identity preserved despite complete change]

## Boundaries (breaks_when)

When the cumulative changes become so substantial that we observe them and consciously recognize the transformation as considerable; then the imagination refuses to ascribe identity.
