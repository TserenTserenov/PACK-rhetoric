# [RHE.ILL.022] Мемы и гены: две эволюции с одной структурой

## Source

«Культура эволюционирует через мемы так же, как биология — через гены. Мем — единица культурной передачи, копируется через коммуникацию, мутирует за часы. Главное отличие: мемы можно менять внутри одной жизни.»

## Structural Core

Ген + биологическая эволюция = Мем + культурная эволюция.

Ключевое отношение: единица наследственной передачи + механизм отбора + скорость мутации. Структура идентична — носители и скорость различаются. Биологическая эволюция занимает поколения, культурная — часы.

## Illustration function

Переносит интуицию о «давлении эволюционного отбора» на культурные убеждения. Объясняет, почему некоторые идеи «выживают» не потому что правильные, а потому что легче распространяются. Активирует категорию: мировоззрение как результат культурного отбора, а не личного выбора.

## Boundaries (breaks_when)

Гены не выбираются сознательно — мемы выбираются. Человек может отвергнуть мем; клетка не отвергает ген. Аналогия ломается на «свободе воли» — принципиальном отличии культурной эволюции. Биологический отбор работает через смерть; культурный механизм отбора принципиально другой.
