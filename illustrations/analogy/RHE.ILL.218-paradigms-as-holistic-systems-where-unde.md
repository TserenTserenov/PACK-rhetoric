# [RHE.ILL.218] Paradigms as holistic systems where understanding parts requires understanding the whole framework first

## Source

Consider the picture of two faces (Figure 1.5) which is unambiguous. Figure 1.6 is ambiguous—we can see it as either a mosque's minaret or two faces. Figure 1.5 is the same picture with the top section removed. We do not see two-thirds of a minaret because we need to see the whole minaret pattern before we can recognise a part of it.

## Structural Core

Part recognition depends on whole-pattern context: same elements belong to different wholes depending on gestalt; elements invisible until whole is perceived

## Boundaries (breaks_when)

When the whole is incomplete or ambiguous, or when fragments alone trigger pattern recognition via alternative gestalt
