# [RHE.ILL.005] IWE как IDE для интеллектуальной работы

## Source

«Работать без IWE — как программировать в блокноте без IDE: синтаксис тот же, логика та же, но среда не понимает контекст, не помнит историю, не подсказывает.»

## Structural Core

Разработчик + IDE = Деятель + IWE.

Ключевое отношение: среда, которая понимает контекст деятельности, помнит историю и усиливает работу — vs нейтральный носитель, который просто сохраняет текст. Оба варианта технически работают, но качество поддержки принципиально разное.

## Illustration function

Переносит знакомый опыт разработчика («я знаю, что IDE меняет всё») на представление об IWE как среде, а не архиве. Активирует категорию «среда поддерживает деятельность, а не просто хранит результаты».

## Boundaries (breaks_when)

Ломается, когда IDE/IWE требует больше когнитивных ресурсов, чем даёт — тогда блокнот (простая среда) действительно лучше. Также: IDE специализирована под один язык, IWE — универсальна.
