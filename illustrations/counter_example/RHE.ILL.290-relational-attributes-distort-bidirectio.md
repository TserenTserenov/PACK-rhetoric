# [RHE.ILL.290] Relational attributes distort bidirectional relationships into one-directional data ownership

## Source

A symmetric relationship (family kinship) is forced into asymmetric model: attribute must belong to one entity, though both entities equally embody the relationship. Choosing which entity "owns" the attribute is arbitrary—there is no logical reason to privilege one over the other.

## Structural Core

Symmetric real-world relation + asymmetric attribute model = forced arbitrary assignment

## Boundaries (breaks_when)

when relationship is truly symmetric and the choice between entities reflects no real-world asymmetry
