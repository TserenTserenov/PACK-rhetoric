# [RHE.ILL.464] Где логическая семантика терпит крах в трактовке идентичности во времени

## Source

In logical semantics, a car object is a three-dimensional extension now and was another different three-dimensional extension yesterday. What then is the class cars? Is it all the extensions, historic and present, or only the present extensions? At each new moment of time, a new class with new members is re-created.

## Structural Core

Fails because логическая семантика не может непротиворечиво определить, какое трёхмерное расширение 'тот же' автомобиль — механизм отказа: класс переопределяется каждый момент, теряя идентичность
