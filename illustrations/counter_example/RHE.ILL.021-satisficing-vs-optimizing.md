# [RHE.ILL.021] Оптимизация поиска поставщика: когда satisficing лучше

## Source

Менеджер тратит 3 часа на выбор поставщика для разовой задачи за 500 рублей, стремясь к оптимальному выбору. Стоимость поиска превышает ценность задачи.

## Structural Core

Fails because: полный перебор вариантов при низких ставках → стоимость процесса выбора превышает ценность самого выбора.

Принцип: оптимальность — это свойство процесса выбора, а не универсальная установка. Для высоких ставок — оптимизируй. Для низких — satisficing (первый достаточно хороший вариант).

## Mechanism of failure

Ошибка происходит не в самом выборе, а в метастратегии: применение полной оптимизации ко всем решениям без учёта их ставок. Это признак неразличения типов задач.

## Application

Полезен при объяснении ZP.4 (оптимизация) — показывает, что сам принцип оптимизации требует meta-оптимизации: знать, когда оптимизировать, а когда нет.
