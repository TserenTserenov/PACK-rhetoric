# [RHE.ILL.013] Евклидова геометрия: аксиоматическое мышление

## Source

Евклид построил геометрию из 5 аксиом. Тысячи теорем — без единого нового допущения. Всё выводится из минимального явного набора. Мощь метода — в минимализме оснований.

## Structural Core

Демонстрирует метод: минимальный набор явных допущений + логический вывод = полная самосогласованная система.

Конкретное применение: аксиоматическое мышление как принцип работы с убеждениями и моделями. Вместо «добавлять допущения по мере нужды» — явно выбрать основания и выводить из них.

## Illustration function

Объясняет, зачем явно формулировать свои исходные допущения при решении задач и построении моделей. Особенно полезен при объяснении ZP (принципов) как оснований, из которых разворачивается система.

## Boundaries (breaks_when)

Если аксиомы выбраны неверно — система разворачивается неправильно (классический пример: замена 5-й аксиомы Евклида порождает неевклидовы геометрии, ни одна из которых не «ошибочна»). Аксиоматика сильна при правильном выборе оснований — слаба при ошибочных.
