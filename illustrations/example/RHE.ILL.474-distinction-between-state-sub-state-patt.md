# [RHE.ILL.474] Distinction between state-sub-state pattern (temporal) and state-sub-class pattern (structural classification)

## Source

Biologists classify caterpillar states by colour: red and green caterpillars do not change colour. Red and green are not states of the caterpillar (which are changeable), but rather sub-classes of the caterpillar class (which are fixed properties). A red caterpillar state has the same extension as a caterpillar state itself.

## Structural Core

Неизменное свойство класса (цвет) соответствует субклассу, а не состоянию; состояния характеризуют изменяемые свойства объекта

## Boundaries (breaks_when)

когда классификационное свойство становится переменным (например, если бы гусеницы могли менять цвет при линьке)
