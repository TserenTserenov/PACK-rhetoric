# [RHE.ILL.014] Рабочая память: ~4 объекта одновременно

## Source

Рабочая память человека удерживает ~4 независимых объекта одновременно (Miller, 1956; уточнение Cowan, 2001). Это не дефект — это архитектурная константа когнитивной системы.

## Structural Core

Демонстрирует принцип: когнитивная нагрузка имеет жёсткий архитектурный потолок.

Конкретное применение принципа: задачи, требующие удержания >4 независимых объектов, неизбежно деградируют без внешних инструментов (экзокортекс, список, диаграмма). Не вопрос концентрации — вопрос архитектуры.

## Illustration function

Снимает самообвинение «я просто не могу сосредоточиться» и заменяет его на инженерный диагноз: «нагрузка превысила архитектурный лимит, нужны внешние инструменты». Объясняет, зачем нужен экзокортекс.

## Boundaries (breaks_when)

Число 4 — для независимых смысловых единиц, не для буквальных слов. Связанные элементы объединяются в чанк и считаются одним объектом (chunking). Эксперт в домене удерживает больше информации за счёт более крупных чанков — не за счёт большего объёма памяти.
