# [RHE.ILL.349] Методология выделения сущностных свойств через элиминацию привычных, но случайных атрибутов

## Source

We have only to attend to our idea of some body, e.g. a stone, and remove from it whatever we know is not entailed by the very nature of body. We first reject hardness; for if the stone is melted, or divided into a very fine powder, it will lose this quality without ceasing to be a body. Again, we reject colour; we have often seen stones so transparent as to be colourless. We reject heaviness; fire is extremely light, but none the less conceived as a body.

## Structural Core

Систематическое удаление акцидентальных атрибутов (твёрдость, цвет, вес) через контрпримеры → остаётся только расширение (extension)
