# [RHE.ILL.438] Sensory heterogeneity does not imply ontological difference; different perceptual modes map to same underlying reality

## Source

When we touch one banana and taste another we get very different feelings; but we have 
no problems in recognising them as belonging to the same type of thing. We should think 
about perceiving time and space in the same way; that we are perceiving the same type 
of thing with different senses.

## Structural Core

Different sensory modes perceive same object-type despite dissimilar qualia, therefore space and time perceived via different modalities should be unified

## Boundaries (breaks_when)

When the different sensory inputs correlate to genuinely different objects rather than different perspectives on one object
