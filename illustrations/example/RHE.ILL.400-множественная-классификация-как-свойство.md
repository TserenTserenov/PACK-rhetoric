# [RHE.ILL.400] множественная классификация как свойство логической парадигмы; экономия структуры через ортогональные измерения

## Source

В substance paradigm первичная субстанция могла принадлежать только одной вторичной.
В логической парадигме один объект может принадлежать столько классам, сколько нужно.
Объект может быть членом класса "свиньи" и класса "самцы животных" одновременно.
Это полезно, исключает необходимость создавать отдельный класс для каждой комбинации.

## Structural Core

один объект + один класс → специализированные типы для каждой комбинации; один объект + N классов → гибкость без множественных типов
