# [RHE.ILL.426] Центральная проблема сохранения идентичности сквозь экстремальные изменения состояния

## Source

We have illustrated this problem before with a lepidopter. Over time it goes through
various stages. The butterfly stage of the lepidopter is so obviously different from
its caterpillar stage. We need to explain why and how these different stages are,
in some sense, the same object.

## Structural Core

Объект претерпевает морфологическую трансформацию на 90%+ (личинка vs имаго) и требует сохранения идентичности через континуальное развитие

## Boundaries (breaks_when)

Если разорвана причинная цепь развития; если личинка и имаго считаются разными объектами по определению; если континуальность во времени не принимается как критерий
