# [RHE.ILL.424] Why dynamic classifications cannot be consistently modeled as objects in logical paradigm; the paradox of change

## Source

Assume that there is a tomato on the table. It is currently green, so a member of the class, green things. Assume it instantaneously turns red. What is happening from an extension viewpoint? If the tomato's change is an instantaneous extension, it must have a colour at that instant. This cannot be red or green, otherwise it would not be changing. So it must be some other colour. Let's assume it is blue. We are back where we started, only with two dynamic classifications—one from red to blue and another from blue to green.

## Structural Core

[Object undergoing state transition] + [Attempt to reify transition as extension] → [Infinite regress of intermediate states]

## Boundaries (breaks_when)

When we accept that transitions exist in time rather than as instantaneous extensions; when we abandon the requirement that all semantic elements must be objects
