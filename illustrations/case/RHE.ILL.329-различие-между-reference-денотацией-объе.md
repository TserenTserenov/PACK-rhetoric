# [RHE.ILL.329] Различие между reference (денотацией объекта) и sense (смыслом концепции)

## Source

Одна денотация (планета Венера) имеет два различных имени и смысла: утренняя звезда (видима в утреннем небе) и вечерняя звезда (видима в вечернем небе). Предложение "Венера есть Венера" тривиально истинно, но "Утренняя звезда есть вечерняя звезда" сообщает людям новый факт.

## Structural Core
