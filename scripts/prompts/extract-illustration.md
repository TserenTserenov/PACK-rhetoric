# Промпт М-RM: экстракция иллюстраций из текста корпуса

> Этот файл — шаблон промпта для headless `claude -p`.
> Используется в rhetoric-miner.py: подставляет {POST_TEXT} и {NEXT_ILL_ID}.
> Не редактировать вручную — это шаблон.

---

Ты извлекаешь риторические иллюстрации из текста поста/руководства для PACK-rhetoric.

## Правила классификации

**Типы (trope_type):**
- `analogy` — переносятся ОТНОШЕНИЯ, а не свойства. structural_core = «[A] соответствует [B], потому что [отношение]». Обязателен `breaks_when`.
- `case` — конкретный прецедент с конфликтом. structural_core = «[Условие A] + [Условие B] → [Результат C]». Должен быть конфликт/напряжение в тексте. Обязательна анонимизация (без имён).
- `metaphor` — переносится образ или качество. structural_core = «[Образ] переносит [свойство], помогая воспринять [концепт] как [новая категория]». Обязателен `breaks_when`.
- `example` — конкретное применение метода/принципа. structural_core = «демонстрирует [метод/принцип] через [конкретное применение]». Должна быть конкретика (цифры, действия).
- `counter_example` — случай, где метод НЕ работает. structural_core = «Fails because [условие] → [механизм отказа]».

**Ключевое требование:**
- `structural_core` для аналогии должен содержать РЕЛЯЦИОННОЕ отношение (не «оба быстрые», а «роль+инструмент»).
- `breaks_when` для аналогии и метафоры — ОБЯЗАТЕЛЕН (условие разрушения переноса).
- Для case — текст должен содержать конфликт/напряжение. Без конфликта → не кейс.
- Анонимизация: никаких реальных имён, ники, узнаваемые биографии → замени на «один практикующий специалист», «участник сообщества», etc.

## Входной текст

```
{POST_TEXT}
```

## Задача

1. Найди ВСЕ риторические иллюстрации в тексте (аналогии, метафоры, кейсы, примеры, контрпримеры).
2. Для каждой заполни карточку строго в формате ниже.
3. Если иллюстраций нет — выведи ТОЛЬКО строку: `NO_ILLUSTRATIONS`
4. Если иллюстрация содержит PII (реальное имя, личные данные) — ПРОПУСТИ или анонимизируй.

## Формат карточки (YAML, одна карточка на ---separator---)

```yaml
---separator---
id: {NEXT_ILL_ID}
trope_type: analogy|case|metaphor|example|counter_example
source_text: |
  [1-3 предложения из исходника, БЕЗ личных имён]
structural_core: "[формула отношения/паттерна/свойства]"
illustrates_concept: "[краткое описание концепта — что иллюстрирует]"
source_domain: "[откуда образ: физика, программирование, медицина, etc.]"
audience_level: 1-5
effect: explain|persuade|scaffold
canonical: true|false
breaks_when: "[условие разрушения переноса — ОБЯЗАТЕЛЬНО для analogy/metaphor/case]"
quality_score: 0.0-1.0
validation_notes: "[краткий комментарий почему этот тип и эта оценка]"
---separator---
```

Выводи ТОЛЬКО карточки (или `NO_ILLUSTRATIONS`). Никаких пояснений, никакого текста вне карточек.
