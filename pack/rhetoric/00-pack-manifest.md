# Pack Manifest — Риторические приёмы (RHE)

## Scope

### Что покрывает этот Pack

- Таксономия риторических приёмов: тропы (метафора, аналогия, парадейгма, метонимия, антитеза)
  и фигуры мысли (энтимема, параллелизм)
- Библиотека иллюстраций — карточки с конкретными кейсами, аналогиями, метафорами, привязанными
  к объясняемым концептам из других Pack'ов
- Схема хранения: формат карточки, поля, критерии качества
- Сервис поиска: «дай мне аналогии для концепта X с уровнем аудитории Y»

### Что НЕ покрывает этот Pack

- Технический writing, документация кода — вне области
- Маркетинговые тексты без привязки к концептам IWE-программы
- Академическая риторика (фигуры, которые никогда не используются в обучении)
- Предметное знание объясняемых концептов — это в Pack домена (PACK-personal, PACK-MIM и т.д.)

## Потребители

| Потребитель | Как использует |
|-------------|----------------|
| Автор руководства | Ищет иллюстрации для концепта перед написанием секции |
| Навигатор-агент (R27) | Подбирает аналогию под уровень и фон читателя |
| R15 Экстрактор (M-RM) | Добавляет новые карточки из корпусов клуба и руководств |
| Автор поста/презентации | Ищет согласованные с программой метафоры |

## Ключевые различения

- **Иллюстрация ≠ Понятие.** Иллюстрация объясняет понятие, но сама понятием не является.
  Понятие живёт в Pack домена. Иллюстрация — здесь.
- **Структурный перенос ≠ Поверхностное сходство.** «Болид = Пилот + Машина» работает потому,
  что сохраняет отношение «роль + инструмент», а не потому что обе системы «быстрые».
- **Канонический приём ≠ Контекстный.** Канонический признан несколькими авторами/источниками,
  воспроизводим. Контекстный — удачная находка в одном тексте, пока не проверен.

## Связанные Pack'и

- PACK-MIM — концепты методологии IWE
- PACK-digital-platform — R15 Экстрактор (роль и SC для mining режима)
