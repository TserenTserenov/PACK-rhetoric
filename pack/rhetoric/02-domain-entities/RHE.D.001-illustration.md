# [RHE.D.001] Иллюстрация (Illustration)

## Определение

**Иллюстрация** — риторический приём, который переносит структурные отношения из знакомого
читателю домена (исходный домен) в объясняемый концепт (целевой домен).

Ключевой критерий: иллюстрация **сохраняет отношения**, а не просто создаёт поверхностное
сходство. Термостат объясняет отрицательную обратную связь не потому что «тоже в доме», а
потому что точно воспроизводит структуру: сигнал рассогласования → управляющее воздействие
→ уменьшение отклонения.

## Поля карточки (схема)

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `id` | string | ✅ | Уникальный идентификатор: `RHE.ILL.NNN` |
| `trope_type` | enum | ✅ | Тип приёма: `analogy`, `case`, `metaphor`, `example`, `counter_example` |
| `source_text` | string | ✅ | Краткое описание иллюстрации (1-3 предложения) |
| `structural_core` | string | ✅ | Что именно переносится: отношение, процесс, структура |
| `illustrates` | list | ✅ | Список `{concept_id, pack_ref}` — что объясняет |
| `source_domain` | string | ✅ | Откуда взята иллюстрация (физика, медицина, спорт...) |
| `audience_level` | 1-5 | ✅ | Минимальный уровень читателя (1=новичок, 5=эксперт) |
| `effect` | enum | ✅ | `explain` / `persuade` / `inspire` |
| `canonical` | bool | — | True если признана несколькими авторами/источниками |
| `breaks_when` | string | — | При каком условии аналогия ломается (граница применимости) |
| `origin_source` | string | — | Откуда извлечена: клуб/руководство/книга/придумана |
| `origin_url` | string | — | Ссылка на источник |
| `quality_score` | float | — | 0.0–1.0, выставляется при верификации |
| `tags` | list | — | Свободные теги |

## Отношения

- **Illustration →[типизируется]→ Trope** (RHE.D.002)
- **Illustration →[объясняет]→ Concept** (из Pack домена, через `illustrates[].concept_id`)
- **Illustration →[добавляется]→ CorpusSource** (через R15 M-RM)

## Критерий качества

Иллюстрация качественная, если:
1. `structural_core` заполнен и содержит отношение (не просто «похоже»)
2. `breaks_when` заполнен (автор думал о границах)
3. Прошла тест: «Если заменить исходный домен другим — отношение сломается?» → Да = структурный перенос, Не Да = поверхностное сходство
