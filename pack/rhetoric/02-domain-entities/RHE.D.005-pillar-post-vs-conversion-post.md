# RHE.D.005: pillar post ≠ conversion post

## Различение
- **Pillar/manifesto:** закрепляется в шапке канала, формирует картину мира, аудитория широкая, структура «N элементов» допустима со сквозной дугой (narrative spine). Метрика — запоминаемость и идентификация читателя.
- **Conversion post:** один персонаж, одна боль, один кейс, один CTA. Метрика — конверсия в следующий шаг.

## Почему важно
Оценка текста по чужой рубрике даёт ложный вердикт: pillar-текст, оценённый как conversion post, получил D «переписать с нуля»; после уточнения функции — консенсус на 4 точечных правках.

## Как применять
Перед оценкой маркетингового текста сначала определить функцию (pillar vs conversion) — разные функции, разные рубрики. Pillar без narrative spine = плоский список. Conversion без персонажа = не работает.
