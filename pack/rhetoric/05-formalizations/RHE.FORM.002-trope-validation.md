# [RHE.FORM.002] Критерии валидации карточки по типу тропа

> Применяется на шаге валидации в Ф3.5 (extraction) и при ручном добавлении карточек.
> Карточка проходит валидацию только если выполнены ВСЕ обязательные критерии своего типа.

---

## analogy — Аналогия

**Суть:** переносятся отношения, а не свойства объектов (Structure-Mapping Theory, Gentner).

### Обязательные критерии

| Поле | Критерий | Тест |
|------|---------|------|
| `structural_core` | Содержит явную формулу отношения | «[A] соответствует [B], потому что [отношение]» — все три части присутствуют |
| `structural_core` | Отношение реляционное, не атрибутивное | «быстрый» — ❌ атрибут. «роль+инструмент» — ✅ отношение |
| `breaks_when` | ОБЯЗАТЕЛЕН | Поле не пустое и содержит условие, а не «N/A» |
| `source_domain` | Отличается от целевого домена | source_domain ≠ pack_ref домен |

### Тест структурного переноса

> Замени исходный домен на другой с теми же отношениями. Перенос работает? → ✅ структурный.
> Замени исходный домен — перенос ломается? → ❌ поверхностное сходство.

Пример (Болид):
- Заменяем болид на «скрипку» → «скрипач + скрипка = Созидатель» — отношение сохраняется ✅
- Значит, Болид — структурный перенос, а не образ скорости.

### Антипаттерны (FAIL)

| Антипаттерн | Почему FAIL |
|-------------|-------------|
| `structural_core: "похоже на X"` | Нет отношения, только сходство |
| `structural_core: "оба быстрые"` | Атрибутивное сходство, не реляционное |
| `breaks_when: "N/A"` | У любой аналогии есть граница — её нужно найти |
| source_domain = pack_ref | Аналогия внутри одного домена = тавтология |

## case — Кейс

**Суть:** конкретный (обобщённый) прецедент, который переносит паттерн поведения.

### Обязательные критерии

| Поле | Критерий | Тест |
|------|---------|------|
| `source_text` | Содержит конфликт | В тексте есть напряжение, проблема, противоречие — не просто «произошло X» |
| `source_text` | Обезличен | Нет личных имён, нет «я как-то», нет биографических привязок |
| `structural_core` | Формат паттерна | «[Условие A] + [Условие B] → [Результат C]» — три части |
| `breaks_when` | Тест применимости | Условие, при котором паттерн не работает (не «N/A») |

### Тест конфликта

> Убери напряжение из `source_text`. Осталось что-то интересное? → ❌ не кейс, а список фактов.

Пример (Земмельвейс):
- С конфликтом: «правильный метод + угроза статусу врачей → отторжение» ✅
- Без конфликта: «врач предложил мыть руки, это снизило смертность» ❌ — список фактов

### Антипаттерны (FAIL)

| Антипаттерн | Почему FAIL |
|-------------|-------------|
| `source_text` без конфликта | Кейс без конфликта не запоминается и не транспортирует |
| «Я однажды видел как...» | Нарушает анонимность → нельзя публиковать |
| `structural_core: "произошло X"` | Нет формулы паттерна |
| Конкретные имена компаний/людей | Персонализация ≠ обобщение |

## metaphor — Метафора

**Суть:** переносится образ или свойство, создающее новую категорию восприятия.

### Обязательные критерии

| Поле | Критерий | Тест |
|------|---------|------|
| `source_text` | ≤3 предложения | Метафора должна работать как вспышка, не развёрнутое объяснение |
| `structural_core` | Содержит переносимое свойство/качество | «[Образ] переносит [свойство/качество], которое помогает воспринять [концепт] как [новая категория]» |
| `breaks_when` | ОБЯЗАТЕЛЕН | Когда буквальное прочтение разрушает образ |

### Тест категоризации (Hofstadter)

> Метафора активирует категорию восприятия? → ✅. Просто «звучит красиво»? → ❌.

Пример («IWE — экзоскелет»):
- Категория: «усиливающий инструмент, а не замена». Это меняет, как человек думает о роли IWE ✅
- «IWE — это помощник» — просто слово, не категория ❌

### Антипаттерны (FAIL)

| Антипаттерн | Почему FAIL |
|-------------|-------------|
| `source_text` > 5 предложений | Метафора потеряла компактность |
| `structural_core: "красивый образ"` | Нет переносимого свойства |
| `breaks_when` пустой | Метафора без границ — буквально опасна |

## example — Пример

**Суть:** конкретное применение метода/принципа, снижающее когнитивную нагрузку (Worked Examples Effect).

### Обязательные критерии

| Поле | Критерий | Тест |
|------|---------|------|
| `source_text` | Конкретный, не абстрактный | Содержит специфику: цифры, действия, результат |
| `structural_core` | Формат: «демонстрирует [метод/принцип] через [конкретное применение]» | Две части присутствуют |
| `effect` | `explain` (default для примеров) | Пример объясняет КАК, не убеждает ЗАЧЕМ |

### Тест конкретности

> Читатель может повторить действие, не имея дополнительных данных? → ✅. «Это примерно так» → ❌.

### Антипаттерны (FAIL)

| Антипаттерн | Почему FAIL |
|-------------|-------------|
| «Например, это можно делать...» без конкретики | Псевдопример — нет деталей |
| `structural_core`: пересказ source_text | Нет обобщения до метода/принципа |

## counter_example — Контрпример

**Суть:** случай, где метод/принцип НЕ работает — обозначает границу применимости и прививает против ошибочного применения (Inoculation Theory).

### Обязательные критерии

| Поле | Критерий | Тест |
|------|---------|------|
| `source_text` | Конкретная ситуация отказа | Не «иногда не работает», а «при условии X Y не работает потому что Z» |
| `structural_core` | Формат: «Fails because [условие] → [механизм отказа]» | Две части присутствуют |
| `audience_level` | ≥ 3 | Контрпримеры — не для новичков (демотивируют без контекста) |
| `breaks_when` | Не применимо (N/A разрешён) | Контрпример сам является границей |

### Тест механизма

> Понятно, почему метод ломается, а не просто что ломается? → ✅. «Не сработало» → ❌.

### Антипаттерны (FAIL)

| Антипаттерн | Почему FAIL |
|-------------|-------------|
| `structural_core: "не работает"` | Нет механизма отказа |
| `audience_level: 1` | Начинающий без контекста услышит «это бесполезно» |

## Процедура валидации (Ф3.5 и далее)

1. Определить `trope_type` карточки
2. Проверить обязательные критерии из таблицы выше
3. Применить тест для данного типа (структурный перенос / конфликт / категоризация / конкретность / механизм)
4. Если хотя бы один обязательный критерий не выполнен → карточка в `illustrations/pending/` со статусом `draft`
5. Если все выполнены → `illustrations/{trope_type}/` со статусом `active`, `quality_score` ≥ 0.7
