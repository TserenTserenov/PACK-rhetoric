# [RHE.METHOD.008] Карта возражений через панель персонажей-скептиков

> **Риторический метод.** Pre-validation контента до живой встречи. Применим к вебинару, семинару, питчу с предсказуемой аудиторией.

## Суть метода

Перед встречей строится карта возражений (≥8 типов по устройству аудитории), затем контент прогоняется через 4–6 персонажей-скептиков — role-play реальных участников. После правок документ проверен на «худший случай».

**Ключевой принцип:** скептик-персонаж задаёт вопросы жёстче реального участника. Документ, прошедший таких скептиков, устойчив в зале.

## Структура карточки возражения

| Поле | Содержание |
|------|------------|
| Кто сказал, как | Цитата типичного участника |
| Скрытое допущение | Что участник считает истиной |
| Механизм возражения | Почему именно это возражение |
| Ответ-заготовка | Голосом ведущего |
| Ход для встречи | Конкретная фраза / вопрос / упражнение |
| Проверка скептиком | Версия персонажа-скептика |

## Алгоритм применения

1. Составить список типов возражений (например: «слишком мелко», «уже знаю», «мне не подходит», «дорого», «нет времени», «не верю»)
2. Написать карточку для каждого типа по структуре выше
3. Создать 4–6 персонажей-скептиков из реальной аудитории (имя, биография 1–2 строки, главное возражение)
4. Прогнать каждую карточку через каждого скептика: «что возразит этот персонаж?»
5. Внести правки; спорные вопросы вынести в §6 (открытые вопросы для встречи)

## Когда работает

- Встреча с предсказуемой аудиторией (есть данные о прошлых встречах, интервью, опросах)
- Высокая ставка: вебинар-продажа, первый пилот, презентация стейкхолдерам
- Тема вызывает сопротивление (смена привычек, новый фреймворк, непопулярное решение)

## Когда ломается

- Аудитория незнакома: персонажи-скептики угаданы, карточки умозрительны
- После 40+ правок документ становится «оборонительным» — перегружен объяснениями, теряет живость
- Метод не заменяет живую обратную связь: одна реальная беседа с участником эффективнее 40 карточек
