```yaml
---
id: RHE.ILL.NNN               # уникальный номер, авто-инкремент
trope_type: analogy            # analogy | case | metaphor | example | counter_example
canonical: false               # true если ≥2 независимых источника подтверждают
audience_level: 2              # 1-5: 1=новичок, 5=эксперт; минимальный уровень

  - concept_id: PD.D.042      # ID концепта из Pack

```

## Тело карточки (обязательные секции)

```markdown
# [RHE.ILL.NNN] Название иллюстрации

## Иллюстрация

Краткое описание (1-3 предложения). Только то, что нужно для понимания приёма — без лишнего контекста.

## Структурное ядро

Что именно переносится из исходного домена в целевой. Формат:
«[Элемент A] соответствует [Элемент B], потому что [отношение].»

Пример: «Пилот соответствует человеку, болид — IWE, потому что
оба — роль + усиливающий инструмент (Созидатель = человек с IWE).»

## Ломается когда

При каком условии аналогия перестаёт работать или вводит в заблуждение.
Обязательно для analogy и metaphor.

## Как использовать

Контекст применения: на каком этапе объяснения, для какого эффекта, как вводить.
```

## Опциональные секции

```markdown
## Происхождение

Откуда взята иллюстрация (клуб, руководство, книга, придумана). Ссылка если есть.

## Связанные иллюстрации

- RHE.ILL.NNN — [название] (похожий приём / альтернатива / противоположность)
```

## Валидация (выполняется при добавлении)

- [ ] `structural_core` содержит явное отношение (не просто «похоже»)
- [ ] `breaks_when` заполнен (для analogy и metaphor)
- [ ] `illustrates` ссылается на существующий концепт в Pack (проверить `concept_id`)
- [ ] Тест структурного переноса пройден: замена исходного домена ломает перенос
- [ ] `audience_level` обоснован: почему именно этот уровень?
