# [RHE.METHOD.006] Порядок тезисов для думающей аудитории

> **Риторический метод.** Требует [RHE.METHOD.004](RHE.METHOD.004-bridge-phrase.md) (мост-фразу) при нарушении логического порядка — использовать вместе, не по отдельности.

## Суть метода

Для аудитории, которая пришла думать, а не разогреваться (например, читатели, целенаправленно подписавшиеся на разбор системного мышления), начинать текст с контринтуитивного/дискомфортного тезиса — не с тёплого захода. Дискомфорт в начале удерживает внимание сильнее, чем комфортный разогрев, если аудитория ценит именно содержательное столкновение.

Пример из практики: порядок тезисов 3→1→2 (не 1→2→3) — каждая позиция обоснована отдельно, начиная с самой контринтуитивной.

## Алгоритм применения

1. Определить, какой тезис вызовет наибольшее сопротивление/несогласие у целевой аудитории.
2. Поставить его первым, с чёткой формулировкой (не смягчённой).
3. Остальные тезисы выстроить как последовательное снятие первоначального сопротивления.
4. Проверить каждый переход на кажущееся противоречие — если есть, вставить мост-фразу (RHE.METHOD.004).

## Когда работает

- Аудитория явно выбрала контент ради содержания, не ради комфорта (нишевая, вовлечённая аудитория, например корпоративный блог с думающими читателями).
- Контринтуитивный тезис действительно обоснован дальше в тексте, не брошен голословно.

## Когда ломается

- Аудитория смешанная (часть пришла разогреться, часть — думать) — контринтуитивное начало отталкивает часть без реального выигрыша у другой части.
- Нарушение порядка применено без моста между тезисами — читает как непоследовательность, не как приём.

## Связь с другими кандидатами

Обоснование этого метода прямо ссылается на необходимость мост-фразы при нелинейном порядке — оба кандидата обрабатывались как связанная пара, не по отдельности.
