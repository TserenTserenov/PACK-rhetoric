# RHE.METHOD.010 — Двухфразовый хук: утверждение + скрытый предел инструмента

## Суть метода

Открывающий двухфразовый хук для поста о когнитивном инструменте, где инструмент тренирует ресурс, но не учит им пользоваться.

**Структура:**
```
«{Инструмент} {положительное утверждение}. Но {скрытый предел второго порядка}.»
```

**Эталон:** «Медитация качает внимание. Но не учит им пользоваться.»

- Первое предложение = common belief (аудитория соглашается)
- Второе предложение = скрытый предел (аудитория останавливается)
- «Но» — точка разрыва ожидания

## Условие применимости

Метод работает, когда выполнены оба условия:
1. Инструмент имеет **измеримый тренировочный эффект** (качает конкретный ресурс)
2. Применение ресурса **отделено от тренировки** (жим лёжа ≠ умение драться)

**Тест переносимости:** «Инструмент X тренирует Y, но не учит Y применять» → структура работает. Примеры: медитация/внимание, спорт/координация, чтение/аналитика.

## Расширение: развёрнутая метафора после хука

Хук открывает, метафора объясняет разрыв:
- «Медитация — жим лёжа для внимания» → сила есть, применение — отдельный навык
- «Чтение — тренажёр для словаря» → слова есть, аргументация — отдельно

## Связи

- RHE.METHOD.001 (And-But-Therefore): союз «Но» — аналогичная техника разрыва; ABT работает на уровне нарратива, этот метод — на уровне открывающей фразы
