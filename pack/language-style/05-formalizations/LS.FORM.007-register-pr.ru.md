# [LS.FORM.007] Регистр PR

> Описание Pull Request. Позиция нейтральная, точность максимальная: аргументация слияния с контекстом для ревью. Источник правил: агент-агентная база (LS.D.003). Жанр: суть изменения + обоснование + план проверки + связанные артефакты. Отличие от коммита: PR аргументирует слияние, коммит фиксирует изменение.
