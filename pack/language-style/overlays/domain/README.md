# Наложение по домену (overlay/domain)

> Кросс-осевой слой каскада, отвечает за ось **поля** (что говорим). Накладывается на собранный базовый регистр. Порядок каскада: `base → domain → market → user`.

## Что держит

Профиль предметной лексики домена: какие понятия активны для регистра в данном домене. **Не свой словарь** — ссылка на идентификаторы графа понятий WP-415 (single source).

Формат записи (заготовка, наполняется в Ф5):
```yaml
# overlays/domain/<pack-id>.yaml
domain: personal-development
concepts:        # ссылки на узлы графа понятий (RU/EN-пары там)
  - cp.rhy
  - cp.wld
jargon_whitelist: []   # термины домена, допустимые без перевода
```

## Чего НЕ держит (OwnerIntegrity)

- Переводных пар терминов RU/EN — они в графе понятий WP-415, не дублируются здесь.
- Полного определения понятия — оно в доменном паке.

## Тест границы

«Меняет ли это, ЧТО говорим (предметные слова)?» Да → доменное наложение. «Меняет ДЛЯ КОГО (сегмент)?» → рыночное наложение (`overlays/market/`).
