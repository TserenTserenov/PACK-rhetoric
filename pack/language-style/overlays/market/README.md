# Наложение по рынку (overlay/market)

> Кросс-осевой слой каскада, отвечает за сегмент аудитории и канально-условные правки (кому и с учётом чего). Накладывается ПОСЛЕ доменного (`base → domain → market → user`), поэтому может переопределять доменную лексику (most-specific-last, как CSS specificity).

## Что держит

Профиль рыночного сегмента (Мир / Россия по модели тиров WP-415):
```yaml
# overlays/market/<market>.yaml
market: ru
audience_segment: novice
tone_overrides:        # правки тона под сегмент
  formality: +1
channel_conditional:   # канально-условные правки (НЕ выбор канала)
  telegram:
    note: "регуляторный тон для RU-рынка"
```

## Граница: рынок влияет на стиль при канале, НЕ выбирает канал

Market-overlay несёт **канально-условные** стилевые правки («для RU-рынка в Telegram — такой тон»), но какой именно канал активен — рантайм-факт интерфейса. Выбор канала остаётся за интерфейсом IWE (различение 1 Ф1 цело).

## Связь с WP-415

Соответствует решению WP-415 «один канонический набор паков; рыночная специфика = overlay». Рынок и есть market-overlay.
