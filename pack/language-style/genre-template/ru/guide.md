# Шаблон жанра: руководство

> **Человекочитаемый скелет** для автора универсального руководства.
> Персональная подстройка (под ступень/bottleneck пилота) приходит отдельным слоем из системы
> персональных руководств (WP-300), здесь НЕ авторится — universal остаётся универсальным.

## Структура

1. **Зачем (мотивировка).** Какую проблему решает метод, без воды.
2. **Что это (определение).** Метод в одном абзаце.
3. **Как (шаги).** Пронумерованные шаги, каждый проверяемый.
4. **Пример.** Один конкретный прогон метода.
5. **Типичные ошибки.** Чего избегать (негативное определение).
6. **Проверка освоения.** Как понять, что метод работает.

## Guidance (подсказки автору)

- Универсальное руководство = метод для всех, без персональных метрик (RCS). Персональное — проекция под пилота (WP-300), отдельный артефакт.
- Академический регистр: точность определений, но без академизма-ради-академизма.
- Каждый шаг — действие, не описание.
