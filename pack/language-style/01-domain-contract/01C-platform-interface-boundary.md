# Граница платформа / интерфейс (дисциплина языковых стилей)

> Контракт финальной фазы Ф10. Фиксирует, что держит **платформа** (знание стиля) и что —
> **интерфейс** (рантайм-факты + рендер). Инвариант WP-392: один вопрос через любой интерфейс →
> один по сути ответ; меняется только канал.

## Кто что держит

| Сторона | Держит | Артефакты |
|---------|--------|-----------|
| **Платформа (суть)** | знание стиля: реестр (слоты, владельцы, наложения), компилятор каскада, пресеты, шаблоны жанров, оси тона | `registry/compiler.py`, `05-formalizations/LS.FORM.*`, `02-domain-entities/LS.D.*`, `overlays/`, `presets.yaml`, `genre-template/` |
| **Интерфейс (IWE)** | рантайм-факты: какое событие/канал сработало → ключ; применение выбора пользователя; рендер/инъекция под канал | `registry/dispatcher.py` (событие→ключ), `style_selector.py` (выбор), живые хуки (инъекция) |

## Инвариант

**Один полный ключ → один фрагмент** (детерминизм). **Разные каналы при одном `(reader_meta_class, reader_role)` → фрагменты отличаются ТОЛЬКО рыночным слоем** (если он есть); канал сам по себе в фрагмент не течёт — он лишь выбирает слот. Это и есть «один вопрос через любой интерфейс → один ответ».

## Разрешённые операции диспетчера (граница тонкости)

Диспетчер (интерфейсная сторона) имеет право только на:
1. **маппинг** `событие интерфейса → context_key` (таблица `EVENT_KEYS`);
2. **передачу** рантайм-фактов `domain` / `market`;
3. **вызов** `compiler.compile_key`.

Всё иное в диспетчере — **утечка стилевой логики в интерфейс** (нарушение WP-392). Запрещено: `render_overlay`, `materialize_*`, `select_overlays`, чтение слот-файлов, любые правила стиля. Проверяется структурным тестом (`test_metrics.py`).

## Метрики (дисциплина измеряет себя)

Двусторонние, живут в платформе (`registry/style_metrics.py`):
- **Покрытие (регистр→ситуация):** доля событий диспетчера, покрытых непустым регистром (защита от пустых слотов + флаг намеренного базового регистра).
- **Соответствие (выход→регистр):** механическая проверка (машинные маркеры A10) + семантический стаб (A1/A5 через LLM — отложено).

Перенос метрик в интерфейс нарушил бы границу: интерфейс начал бы «знать» стиль.
