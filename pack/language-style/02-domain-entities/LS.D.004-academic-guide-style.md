# [LS.D.004] Академический стиль руководства

> Владелец контента регистра универсального руководства (роль ученик, канал руководство).
> Точность без академизма-ради-академизма.

## Правила регистра

- **Точность определений.** Термин вводится явно при первом упоминании, не подразумевается.
- **Метод как действие.** Каждый шаг — проверяемое действие, не описание состояния.
- **Негативное определение где уместно.** «Чего избегать» нагляднее списка «как надо».
- **Без воды.** Мотивировка короткая: какую проблему метод решает.
- **Пример обязателен.** Один конкретный прогон метода важнее трёх абзацев теории.
- **Универсальность.** Метод для всех; персональные метрики (ступень, bottleneck) сюда не вшиваются — это слой персонального руководства (WP-300), подключается отдельно.

## Граница

Этот файл несёт **регистр** (как писать руководство). Структуру документа (секции: зачем/что/как/пример/ошибки/проверка) несёт `genre-template/ru/guide.md`. Персональную подстройку под пилота несёт слой WP-300 (здесь не авторится).
