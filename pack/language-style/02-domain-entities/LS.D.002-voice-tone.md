# [LS.D.002] Голос и тон

Практика контент-дизайна (Mailchimp; Nielsen Norman Group, 2016) развела два понятия, которые теория Холлидея держит вместе в оси отношения.

## Голос (примитив, ядро агента)

**Голос** — стабильная узнаваемая подпись автора. Не меняется от ситуации к ситуации. Ортогонален регистру: поверх одного и того же регистра разные агенты звучат по-разному, поверх разных регистров один агент узнаваем.

Свойство: голос — атомарный примитив (не раскладывается на оси), всегда включён.

## Тон (производное, ситуативная настройка)

**Тон** — настройка поверх голоса по ~4 осям:
- формальность,
- юмор,
- уважительность,
- энтузиазм.

Плюс контекст (кто читатель, намерение). Тон серьёзный в отчёте об ошибке, лёгкий в приветствии — голос при этом один.

## Инвариант полного профиля

```
полный стилевой профиль высказывания = регистр + голос + тон
```

Голос ортогонален регистру (стабильный вектор агента поверх ситуативного регистра), иначе «регистр peer-сессии» был бы разным у разных агентов и ломал бы жанровые шаблоны.

## Агент-агентный случай (проекция)

Для мета-класса «агент» тоновое пространство сжато, но не нулевое:
- **stance** (позиция) — проекция тона: нейтральный / деферентный / вызывающий.
- Диапазон stance задаёт роль: исполнитель → нейтральный; напарник → весь диапазон (несогласие и эскалация — его работа).

Детали — LS.SOTA.002 §4.

## Голос автора по корпусу: образцы и стоп-лист

Голос — отличительная подпись автора, поэтому его нельзя задать типичными текстами. Ниже способ, выбранный при сборке норм стиля постов (WP-619). Нормы посчитаны скриптом по 651 посту 2020–2024 годов, отдельно для опубликованного и для черновиков.

1. **Образцы — не «ближайшие к медиане».** Тексты из середины распределения подменяют голос серединой: отличительное в них сглажено.
2. **И не ручной отбор агентом «где голос заметен».** Такой отбор возвращает вкус агента вместо голоса автора.
3. **Механическое правило с вето автора.** На каждую страту корпуса берутся два реальных текста: центр и пик диалогических примет. Индекс примет и потолок 90-го перцентиля задаёт источник. Автор по каждому образцу решает «оставить» или «убрать».
4. **Регистры не сливать.** Черновики не объединяют с опубликованными постами по совпадению медиан: у них разные регистры. Медиану длины отвергли как стилевой признак.
5. **Стоп-лист нейрослопа — по анти-корпусу своего агента.** В текстах автора прошлых лет нейрослопа почти нет, поэтому кандидатов дают тексты своего агента: выражения, которые у агента встречаются заметно чаще, чем у автора. В источнике пилот выбрал порог ×3 и минимум 1 на 1000 слов; каждую строку проверяет автор. Внешние списки не используются.

**Тест.** «Образцы голоса отобраны по близости к типичному или по вкусу агента?» Да → голос подменён серединой или вкусом агента. «Стоп-лист взят из внешнего списка, а не из сравнения текстов своего агента с корпусом автора?» Да → он не описывает штампы своего агента.

**Границы.** Один автор и один корпус. Что образцы «центр + пик» передают голос лучше медианных, в источнике не измерялось: это решение пир-сессии. Числовые пороги — параметры конкретного решения пилота, не универсальная норма. Голос конкретного автора и его стоп-лист хранит владелец контента (`DS-Tseren-Brand/style/0-voice.md`, см. `overlays/author/voice.yaml`); здесь описан только способ их получить.
