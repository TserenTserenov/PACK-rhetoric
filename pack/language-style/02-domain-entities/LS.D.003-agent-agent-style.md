# [LS.D.003] Агент-агентный стиль

> Владелец контента агент-агентных регистров (peer-сессия, handoff, контракт задачи, коммит, PR).
> Инстанциация осей Холлидея на мета-класс «агент» (LS.SOTA.002 §4), не новая онтология.

## Позиция (stance) — диапазон задаёт роль

- **Исполнитель** (контракт задачи, handoff, коммит, PR): позиция всегда **нейтральная**, точность контракта **максимальная**. Исполнителя нельзя сделать менее точным — это ломает контракт.
- **Напарник** (peer-сессия): позиция во всём диапазоне — нейтральная / уступчивая / **спорящая**. Несогласие и эскалация это его работа. Пользователь может сузить диапазон («будь менее спорящим»), но право эскалации ради качества или безопасности остаётся.

## Точность контракта (explicitness)

Объём деталей и явность входов, выходов, инвариантов. Для исполнителя — максимум: ничего не подразумевается молча. Для напарника — достаточная, чтобы аргумент проверялся.

## Контракт качества — 4 максимы Грайса

- **Количество:** не больше и не меньше нужного. Нарушение — избыточность или недосказанность.
- **Качество:** не утверждать ложное или недоказанное. Нарушение — непроверенное как факт.
- **Релевантность:** по делу. Нарушение — иррелевантный вывод.
- **Манера:** ясность, без двусмысленности. Нарушение — неясный контракт.
