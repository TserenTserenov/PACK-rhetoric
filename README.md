# PACK-rhetoric — Риторические приёмы

**Домен:** структурированная коммуникация с интенцией  
**Статус:** draft (WP-340)  
**Версия:** 0.1.0

## Что это

Библиотека риторических приёмов: кейсов, аналогий, метафор и примеров для использования
при создании руководств, постов и презентаций. Каждый приём — карточка с источником,
структурным ядром и привязкой к объясняемым концептам.

## Для кого

- Авторы руководств и постов (ищут иллюстрации для концептов)
- Навигатор-агент (подбирает аналогии под уровень читателя)
- R15 Экстрактор в режиме M-RM (добавляет карточки из корпусов)

## Структура

```
pack/rhetoric/
├── 00-pack-manifest.md         — скоп, граница домена
├── 01-domain-contract/         — контракт + различения
├── 02-domain-entities/         — сущности (Illustration, Trope)
├── 05-formalizations/          — форматы карточек и таксономия
└── 08-service-clauses/         — обещание (RHE.SC.001)

illustrations/                  — хранилище карточек
templates/illustration-card.md  — шаблон для авторов
```

## Как добавить иллюстрацию

Скопируй шаблон `templates/illustration-card.md`, заполни поля, сохрани
в `illustrations/{trope_type}/{concept_slug}.md`.

Обязательные поля: `id`, `trope_type`, `source_text`, `illustrates`, `structural_core`.
